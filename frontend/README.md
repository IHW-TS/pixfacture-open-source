# Frontend (Next.js)

## Quick start
```bash
npm ci
npm run dev
```

## Build and run
```bash
npm run build
npm run start
```

## Environment variables
API routing:
- `NEXT_PUBLIC_API_ORIGIN`: API origin only (scheme + host), no `/api` path.
- `NEXT_PUBLIC_API_PREFIX`: API prefix (default: `/api`).
- `NEXT_PUBLIC_API_BASE_URL`: full API base URL (overrides origin+prefix).

Legal/hosting (required when `APP_ENV=prod|production|staging`):
- `NEXT_PUBLIC_LEGAL_COMPANY_NAME`
- `NEXT_PUBLIC_LEGAL_COMPANY_LEGAL_FORM`
- `NEXT_PUBLIC_LEGAL_COMPANY_CAPITAL`
- `NEXT_PUBLIC_LEGAL_COMPANY_RCS_CITY`
- `NEXT_PUBLIC_LEGAL_COMPANY_RCS_NUMBER`
- `NEXT_PUBLIC_LEGAL_COMPANY_VAT_NUMBER`
- `NEXT_PUBLIC_LEGAL_COMPANY_ADDRESS`
- `NEXT_PUBLIC_LEGAL_COMPANY_EMAIL`
- `NEXT_PUBLIC_LEGAL_COMPANY_PHONE`
- `NEXT_PUBLIC_LEGAL_PUBLISHER_DIRECTOR`
- `NEXT_PUBLIC_LEGAL_HOSTING_PROVIDER_NAME`
- `NEXT_PUBLIC_LEGAL_HOSTING_PROVIDER_ADDRESS`
- `NEXT_PUBLIC_LEGAL_HOSTING_PHONE`
- `NEXT_PUBLIC_LEGAL_PRIVACY_CONTACT_EMAIL`
- `NEXT_PUBLIC_LEGAL_SUPPORT_EMAIL`
- `NEXT_PUBLIC_LEGAL_LAST_UPDATED`

- `NEXT_PUBLIC_ENABLE_PDP_INTEGRATION`

When `APP_ENV` is prod-like, `npm run build` runs `scripts/check-legal-env.mjs` and fails if required
legal variables are missing.
